# لعبة الرعب Horror Game
## Roblox × Resident Evil Prototype

### الفكرة الأساسية 🎮
لعبة رعب 3D من منظور أول الشخص، تجمع بين:
- **Roblox**: الاستكشاف والحرية في الحركة
- **Resident Evil**: الرعب والقتال مع أعداء أقوياء

### قواعد اللعبة 🎯

#### المراحل (Stages)
- **المراحل 1-4**: 4 أعداء في كل مرحلة
- **المرحلة 5 (الأخيرة)**: 6 أعداء

#### كل عدو (Enemy)
- يزيد في القوة حسب المرحلة
- يقترب من اللاعب ويهاجم
- له صحة تقل مع كل ضربة

#### اللاعب (Player)
- صحة 100
- يخسر صحة عند الهجوم من الأعداء
- يجب القضاء على جميع الأعداء للعبور للمرحلة التالية

### التحكم 🎮
| المفتاح | الفعل |
|--------|-------|
| W/A/S/D | الحركة |
| Mouse | النظر حول |
| Click | الهجوم |
| SPACE | قريباً (ستضاف الأفعال المتقدمة) |

### التشغيل 🏃

#### الطريقة الأولى: Python (الأسهل)
```bash
cd game
python -m http.server 8000
# افتح المتصفح على: http://localhost:8000
```

#### الطريقة الثانية: Node.js
```bash
cd game
npx http-server
```

#### الطريقة الثالثة: العمل مع المشروع الأساسي
```bash
npm install
npm start -- --game
```
